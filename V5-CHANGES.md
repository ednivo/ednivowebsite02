# Ednivo GCC SAT v5

## Student-only portal
- Sidebar workspace inspired by modern fellowship/LMS layouts.
- Overview
- Practice
- Upcoming & Recordings
- SAT Syllabus
- SAT Score Calculator
- AI SAT Coach
- Visible student avatar/profile and logout.

## Authentication
- Separate student login page.
- New-student profile capture: name, email, GCC country, country code + phone, class/grade.
- Returning students: email OTP or Google.
- Existing users remain tied to the same Supabase auth user; no second account is created for the same email.
- First-time Google users complete profile once; returning Google users go directly to dashboard.

## Lead magnet
- Email-gated Ednivo SAT syllabus download.
- Original Ednivo PDF based on College Board public content domains.
- College Board branding/PDF is not modified or redistributed.

## SAT score calculator
- SAT score + academic strength + activities + target-university planning.
- Outputs an Ednivo planning/competitiveness estimate, not an admissions probability.
- Recommends retake strategy, profile building and/or AP rigor when appropriate.

## Content
- GCC-first student messaging.
- Country-card border section removed.
- Parent login/dashboard removed from the product.
- Testimonials are marked as samples until replaced with verified GCC student quotes.
